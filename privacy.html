PITA Google Account Base
Android アプリ CP001_A「Gmail添付共通基盤」

適用開始日：2026年10月14日

1. 対象

本ポリシーは、個人利用向け Android アプリ CP001_A（以下「本アプリ」）における情報の取扱いを説明します。P003_B とのメール連携を含みますが、P003_B 自体や、同じ Google 認可プロジェクトを使用する他のアプリ全体を対象とするものではありません。

2. 取得する情報と利用目的

  • Google アカウント情報：メールアドレスとその確認結果を、送信元アカウントの識別・確認に使用します。認可に必要なアクセストークンは、Google API へのアクセスに使用します。
  • 送信情報：宛先、件名、本文、添付ファイルの名前・形式・内容を、利用者が指定したメールの送信に使用します。
  • 受信情報：メールの差出人・宛先等のヘッダー、件名、日時、本文、識別情報、添付ファイルを、受信箱・内容の表示、添付の保存、利用者が指定した連携に使用します。
  • 設定・送信記録：送信元・宛先、容量設定、リレー依頼 ID、依頼元、内容照合用ハッシュ、送信状態、Gmail メッセージ ID 等を、設定の維持、重複送信の防止、結果確認に使用します。

CSV やメール・添付ファイルには、利用者や第三者の個人情報が含まれる場合があります。

3. Google の権限

送信には gmail.send、受信には gmail.readonly、アカウント確認には userinfo.email と openid を使用します。受信機能は読み取り権限で動作し、メールを削除・変更する権限を要求しません。

Google アカウントの認可は Google の仕組みを利用します。本アプリが Google パスワードを入力させたり、独自に保存したりする処理はありません。アプリの設定・送信記録にアクセストークンは保存しません。

4. 送信・共有先

  • Google：認可、アカウント確認、Gmail の送受信のために通信します。送信したメールと添付は Gmail を通じて、指定した宛先とそのメールサービスに渡ります。
  • 連携アプリ P003_B：送信依頼に対して処理結果を返します。受信画面で利用者が引き渡しを選んだ場合、差出人、件名、日時、本文、添付ファイル等を、署名を確認した連携元へ渡します。
  • 利用者が選ぶ保存先：受信した添付を保存する場合、端末またはファイル選択画面で指定したストレージサービスへ書き込みます。

Google 側の取扱いは Google のプライバシーポリシー、各メール・ストレージ・連携アプリ側の取扱いは、その提供者の方針に従います。

5. 保存と保護

送信元・宛先等の設定は、端末内のアプリ専用領域に保存します。リレー依頼の件名・本文・送受信アドレス・添付コピー・処理結果も保存し、送信成功後を含め、一定期間で自動削除する仕組みはありません。

送信元設定とリレー記録・添付コピーは Android の通常バックアップ対象外の領域に保存します。宛先や容量設定は、端末の設定により OS のバックアップ・復元の対象になる場合があります。

受信内容は表示・操作のためにメモリー上で処理します。連携用の受信添付は一時キャッシュに保存し、読取終了時に削除します。残ったものは、次回のキャッシュ作成時に保存から1時間を超えていれば削除対象になります。

Google API との通信は HTTPS を使用します。アプリ間連携は署名・呼出元を確認し、添付の参照権限を制限します。保存データをアプリ独自に暗号化する仕組みはありません。

6. 利用停止と削除

  • Google へのアクセスは、Google アカウントのリンク済みアプリ管理から取り消せます。取り消し後は、再認可するまで対応する Gmail 機能を利用できなくなります。
  • 登録した宛先はアプリの設定で削除し、保存できます。端末内のアプリデータ全体を消去する場合は、Android のアプリ設定から本アプリのストレージ／データを消去してください。設定・送信記録・添付コピーも失われるため、実行前に必要な情報を確認してください。
  • アクセス権の取り消しだけでは、端末内の保存情報は削除されません。本アプリのデータ消去は、Gmail 内のメール、受信者に届いたメール、外部に保存したファイル、連携元のデータ、OS のバックアップを削除する操作ではありません。それぞれの保存先で管理してください。

7. Google API データの利用方針

Google API から取得した情報の利用および他のアプリへの提供は、Limited Use 要件を含む Google API Services User Data Policy に従い、上記の利用者向け機能のために行います。
